# 0.3.0 开发版验收记录

日期：2026-11-26。状态：代码与本地候选包验收，**尚未合并、打 tag 或发布**。本体与插件各自通过 PR 评审；GitHub 商店页面需合并后部署，不能把本地预览当作已上线。

## 需求与实现

| 需求 | 实现与验收依据 |
| --- | --- |
| 架构与性能 | 保留 Rust + Slint 原生 UI，裁剪未用渲染与 Wasmtime 特性；分离内核生命周期、更新、商店、备份、同步、诊断模块；插件编译缓存有容量与空闲回收策略 |
| 主界面与插件 UI | 主界面统一导航、状态与按钮样式；设置分为四页，插件分已安装/商店与插件内部页面；Teldrive 五页、图床五页、KVault 三页。真实窗口验收名称、角色、密码遮蔽和关键操作 |
| GitHub 页面与持续迭代 | 中英 README、架构图、贡献与版本规范、Issue/PR 模板、CODEOWNERS、格式/测试/打包 CI、不可覆盖的 Release 资产、商店清单审核与 Pages 工作流 |
| 无 GUI 调试 | 版本、JSON 离线诊断、导入预检、插件列表、语义结构导出；真实 UIA 与静态导出明确区分。未知参数在建窗前失败 |
| setup / portable | Inno Setup 按用户安装；便携标记切换数据目录；固定来源的 rclone 与插件、双层 hash 核对、许可证与 SHA256SUMS |
| 新版检测与应用内更新 | 检查版本、有限大小下载、校验；便携版退出后按计划替换与失败回滚，安装版启动校验后的安装程序。真实跨版本更新列为发布前验收项 |
| 一键 rclone 内核化 | 默认受管内核，随机回环端口与每次启动的 RC 凭据，Job Object 管理本应用子进程；保留外部连接。oneclick 新版仅提示迁移，不再启动内核 |
| 动态远程与 KVault 插件 | 新建列表来自实际 `config/providers` 与启用插件的派生预设；无硬编码兜底清单。预设保存使用真实 `base_type` 并保留插件默认参数；旧 KVault 配置继续可编辑 |
| 插件商店 | 应用内浏览、权限和来源展示、安装与更新；静态网页支持筛选与详情，清单通过 PR 审核收录。索引仅列真实已发布资产 |
| 导出插件设置与 WebDAV | 配置文件包含插件信息、设置与同步任务，不含插件包体；默认隐藏凭据，显式包含敏感数据时才导出。WebDAV PUT/GET 真实回环往返及导入预览、合并已验证 |
| 远程类型搜索 | 关键字筛选保持选中类型与表单一致，无结果阻止保存；真实内核与 KVault 类型均在窗口中核对 |
| 移除无效 HTTP 设置模块 | 设置页删除原“内嵌 HTTP 服务”卡片；插件 HTTP 入口的底层兼容代码保留，不影响既有图床协议 |
| 轻量模式 | 默认隐藏到托盘 10 分钟，可配置延迟；隐藏时销毁原生窗口资源，延迟后释放大模型与 WASM 缓存。保留后台内核、同步和用户草稿，恢复时重建视图 |
| Teldrive 更新 | 检查新版本、校验 ZIP/EXE、维护已拥有的进程句柄、健康检查、失败回滚；使用假能力调用测试覆盖更新派发，真实服务升级仍需测试环境 |
| 文件夹同步 | 默认本地到远程、6 小时、只复制不删除，可切换方向和周期；任务占用避免重复提交，断网不会误判作业结束，内核代次避免误控其它作业。隔离本地后端双向复制验证目标多余文件保留 |

## 隔离集成与 UI 验收

- 独立 `RCGUI_DATA_DIR`、`RCLONE_CONFIG` 与随机端口运行新版；用户旧 GUI 和旧 rclone 一直保留运行。
- 受管内核正常退出与主程序被强制结束两条路径均核对自己的子进程退出；不结束旧实例。
- 使用本地测试文件验证同步两个方向、复制模式不删除目标额外文件。未操作真实云端文件。
- WebDAV 回环服务器实际接收默认脱敏和显式含假密码的两份导出：插件设置和任务存在，默认不带嵌套插件密钥，临时 RC 凭据始终不在导出中。
- 下载配置后先展示导入预览；应用后普通插件设置变化，已有本机密码保留，导入同步任务重置运行状态，启动项摘要保持不变。
- 真实 Windows UIA 验证关键页面、插件标签与设置控件。修复自定义输入框 `SetValue` 未更新模型、插件页底部控件被裁切、筛选类型后表单未切换和恢复页码被清空等验收问题。
- 静态商店网页完成桌面/窄屏预览、搜索与详情检查。验收图片中的 QA 数据已标识，不作为在线商店实际目录。

## 本机性能采样

Windows 11 10.0.26300、Ryzen 7 9700X、内存约 47.1 GiB，0.3.0 release 构建，空配置三次采样，窗口句柄作为就绪信号，等待 10 秒后读取。启动中位 87.9 ms（最大 124.6 ms）；GUI 工作集中位 57.0 MiB（最大 57.4 MiB），私有内存中位 24.4 MiB（最大 24.5 MiB），不含独立 rclone 进程。可执行文件 35,735,040 字节；portable 压缩包 44,555,108 字节，解压内容 122,706,630 字节。

另一次加载 Teldrive 面板的单次观察：前台工作集 64.8 MiB、私有 32.1 MiB；隐藏 100 秒进入轻量模式后工作集 5.1 MiB、私有 14.7 MiB。工作集受系统回收影响，不能作为实际释放内存的唯一依据；上述数字仅代表本机一次观察，不代表跨机器保证。恢复后维护页面和受管内核仍在。
